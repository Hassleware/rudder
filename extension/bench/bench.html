Filter benchmark

Scores the filter the viewer uses (probe.js) on 10 filters: 5 the method was chosen on, and 5 held out. Each passage "fires" if any token's score (smoothed a little) goes over the filter's fixed threshold. AUROC = on-topic passages ranked above off-topic ones (1 = perfect, 0.5 = guessing). Uses the GPU for about a minute and clears the chat's memory (the next message re-reads the chat). The search behind the method is research/probe-research.mjs.
